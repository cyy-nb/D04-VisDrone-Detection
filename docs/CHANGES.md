# 数据转换优化说明

## 2026-10-13

- 将 VisDrone 转换类别从 11 类修正为项目采用的 10 类，避免生成模型和 COCO 类别表之外的标签。
- 先裁剪边界框角点再归一化，丢弃无穷、NaN、负尺寸及完全在图外的框。
- 检查输入目录、图片和缺失标注，避免错误路径或缺失标注被误当作正常背景数据。
- 图片复制使用 `shutil.copy2`，避免一次性将整张图片文件读入 Python 字节对象。
- 两个转换脚本支持命令行路径配置，保留原来的默认路径。
- COCO 转换放入函数和主入口，导入模块不会再读写数据；排序图片以稳定 ID，及时关闭图像文件，检查类别和数值合法性。
- 加入合成图片回归测试，覆盖类别过滤、边界裁剪、COCO 坐标与面积、空标注和缺失标注。

旧数据若含类别 10（others），请重新生成 YOLO 标签及 COCO JSON。该修复会改变评估数据；比较模型时应统一使用重新生成的数据，不要混用新旧指标。

本次优化聚焦数据转换正确性和可维护性，不宣称检测精度或推理速度提升。完整模型训练及真实数据评估需在准备好依赖、数据和权重的环境执行。
